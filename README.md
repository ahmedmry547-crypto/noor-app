# نور القرآن الكريم - تطبيق إسلامي (Flutter)

## البناء
1. ثبّت Flutter (https://docs.flutter.dev/get-started/install) وAndroid Studio.
2. افتح الترمينال داخل هذا المجلد:
   - Windows: `build_apk.bat`
   - Mac/Linux: `./build_apk.sh`
3. الـ APK هيطلع في: `build/app/outputs/flutter-apk/app-release.apk`

## بدون تثبيت Flutter
ارفع المجلد على GitHub ثم Actions > Build APK > Run workflow، وحمّل الملف من Artifacts.

## ملاحظة
القرآن النصي كاملًا مضمّن داخل التطبيق ويعمل بدون إنترنت من أول تشغيل؛ لا تحتاج لفتح السورة بالنت أول مرة. البحث في النص القرآني يعمل أوفلاين أيضًا. مصدر النص: Tanzil Project، ويجب إبقاء نسبة المصدر والرابط وفق شروطه.

## تحديثات التلاوات والأذكار
- التلاوات الصوتية تعتمد على **MP3Quran API v3** لجلب قائمة القراء والمصاحف/الروايات والسور بشكل ديناميكي، بدل قائمة ثابتة.
- يمكن تشغيل السورة مباشرة من الإنترنت أو تشغيل النسخة المحلية إذا كانت محمّلة.
- يمكن تنزيل سورة منفردة أو تنزيل المصحف المتاح كاملًا، مع حفظ الملفات داخل مساحة التطبيق للعمل بدون إنترنت.
- توجد شاشة مستقلة للتنزيلات لمعرفة الملفات والمساحة المستخدمة وحذفها.
- أضيفت أذكار الصباح والمساء الموجودة في الصورة المرفوعة إلى القائمة مع الحفاظ على تصميم التطبيق الحالي، مع الإبقاء على أذكار النوم وبعد الصلاة.

مصدر التلاوات: MP3Quran — https://www.mp3quran.net/ar/api
