تحديث نور V2 — MP3Quran + تحميل أوفلاين + الأذكار

هذا التحديث يضيف:
1) قائمة كبيرة من القراء من MP3Quran API بدل قائمة ثابتة صغيرة.
2) اختيار القارئ والقراءة/المصحف إذا كان للقارئ أكثر من رواية.
3) اختيار السورة وتشغيلها Streaming عبر الإنترنت.
4) تحميل السورة داخل التطبيق وتشغيلها لاحقًا بدون إنترنت.
5) زر تحميل المصحف المتاح كاملًا للقارئ، مع تحذير قبل بدء التحميل.
6) حفظ قائمة التنزيلات وحذف السورة المحملة.
7) تحديث قسم الأذكار بالبيانات الموسعة الموجودة في azkar_data.dart.

طريقة الرفع إلى GitHub:
- لا ترفع ملف ZIP نفسه داخل المشروع.
- فك الضغط.
- استبدل الملفات بنفس المسارات:
  lib/features/azkar/azkar_data.dart
  lib/features/quran/quran_screen.dart
  lib/features/quran/audio_screen.dart
  lib/features/quran/audio_downloads.dart
  lib/features/quran/mp3quran_service.dart
  pubspec.yaml
- بعدها اعمل Commit changes مباشرة على main.
- GitHub Actions سيبدأ بناء APK تلقائيًا لأن workflow يعمل عند push على main.

مهم:
- أول مرة لعرض قائمة القراء تحتاج إنترنت.
- بعد تحميل السورة، تشغيلها يتم من ملف محلي داخل التطبيق ولا يحتاج إنترنت.
- تحميل المصحف كاملًا قد يحتاج مساحة كبيرة جدًا؛ الأفضل تحميل السور التي تحتاجها فقط.
- مصدر بيانات القراء والروابط الصوتية: MP3Quran.net API.
